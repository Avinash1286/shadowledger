# Security policy

ShadowLedger is hackathon software and has not received an independent audit. Do not use it for production payroll or funds you cannot afford to lose.

To report a vulnerability, use GitHub’s private vulnerability-reporting feature for `Avinash1286/shadowledger`. Include affected commit, reproduction steps, impact, and any suggested fix. Do not include real keys, viewing data, payroll records, or mainnet funds in a report. Please allow a reasonable remediation window before public disclosure.
